# Red Glass Releases

Official release binaries for [Red Glass](https://red-ai.app) - Admin AI Desktop Application.

## Downloads

Visit our [releases page](https://github.com/Niffb/red-releases/releases) to download the latest version.

### macOS
- **Apple Silicon (M1/M2/M3/M4)**: `Red Glass-1.0.0-arm64.dmg`
- **Intel**: `Red Glass-1.0.0.dmg`

### Windows
Coming soon.

## Installation

1. Download the appropriate DMG for your Mac
2. Open the DMG file
3. Drag Red Glass to your Applications folder
4. Launch Red Glass from Applications
